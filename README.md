# TiniTalk Admin

TiniTalk Admin — Android-приложение для настройки и администрирования серверов TiniTalk напрямую по SSH, без отдельного управляющего сервера.

Приложение позволяет:

- добавлять VPS
- выполнять первоначальную установку TiniTalk
- проверять состояние сервера
- управлять пользователями

Для постоянного SSH-доступа используются ключи, защищённые Android Keystore.

## Сборка

Потребуются JDK 17, Android SDK и Make.

Собрать отладочный APK:

```sh
make client
```

Готовый файл появится в `dist/tinitalk-admin-debug.apk`.

Собрать уменьшенный оптимизированный dev-APK (ARM64, R8):

```sh
make client-min
```

Результат: `dist/tinitalk-admin-min.apk`.

Обе dev-сборки подписываются отладочным ключом. `make check` запускает тесты,
lint и сборку debug/min; релизный ключ для этого не нужен.

### Подписанный release

Нужен отдельный постоянный ключ подписи TiniTalk Admin. Храните его и пароли
в защищённом месте с резервной копией: они понадобятся для следующих выпусков.
Не используйте debug-ключ или ключ основного приложения.

Создайте локальный `keystore/release.properties` (папка `keystore/` игнорируется Git):

```properties
storeFile=keystore/tinitalk-admin-release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=tinitalk-admin-release
keyPassword=YOUR_KEY_PASSWORD
```

`storeFile` задаётся относительно корня проекта либо абсолютным путём;
в Windows используйте `/` в пути. Файл имеет формат Java Properties:
спецсимволы в паролях, например `\`, нужно экранировать.

```sh
make client-release
```

Результат: `dist/tinitalk-admin-v<VERSION>.apk`. Версия задаётся в
`app/build.gradle.kts` и используется также в интерфейсе приложения.
При каждом новом выпуске увеличивайте `versionCode`.
Для проверки соответствия тегу: `make client-release GRADLE_ARGS="-PreleaseTag=v<VERSION>"`
(подставьте версию вместо `<VERSION>`).
Без настроенной подписи release-сборка завершается ошибкой, без подмены debug-ключом.

Release с другим сертификатом нельзя установить обычным обновлением поверх dev-версии.
Удаление приложения уничтожит его локальные данные и SSH-ключи; заранее обеспечьте
доступ к VPS через первоначального SSH-пользователя. Смена подписи также может изменить
маркер ключа на VPS. Подробности: [подпись Android-приложений](https://developer.android.com/studio/publish/app-signing).
